# RELOOT v1.1 (React + Vite + Tailwind + API de Imágenes + Mercado Pago)

## Ejecutar el Frontend
```bash
npm install
npm run dev
```

## API de Imágenes (Pexels API + Respaldo Curado)
Funciona de inmediato sin configurar nada usando imágenes de respaldo curadas para cada producto.
Si deseas consultar la API de Pexels en vivo:
1. Crea un archivo `.env` en la raíz a partir de `.env.example`.
2. Agrega `VITE_PEXELS_API_KEY=tu_api_key_de_pexels`.
3. Reinicia `npm run dev`.
